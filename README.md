# The poem about permission

A short poem about agency: the power to ask and to be given. A child asks her mother for the scissors; the mother does not refuse the blade, she turns it in her palm and lays it down handle first. Permission, the poem says, is not a refusal but a careful handing over — the sharp end offered last, and the cut left to the one who asked.

`main.ts` (Node 22, standard library only, no network) writes the poem to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`, falling back to `/output`. The program is fully deterministic: two runs write byte-identical files (219 characters, UTF-8).
